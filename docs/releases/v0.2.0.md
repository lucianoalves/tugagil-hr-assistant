# Release Notes — v0.2.0

**Release date:** 2026-09-05

## Summary
`v0.2.0` delivers the first executable baseline for TugaAgil HR Assistant.
The release introduces a working validation endpoint, deterministic parser/scorer pipeline, PII redaction, and a smoke test.

## Highlights
- Added `POST /api/validate` API endpoint.
- Added parser baseline for CV/LinkedIn text normalization and section detection.
- Added deterministic scoring baseline with explainable score breakdown.
- Added PII redaction (email, phone, URL) before optional LLM layer usage.
- Added one end-to-end smoke test for the validation flow.

## API Contract
### Request
```json
{
  "cv_text": "Summary ... Experience ... Skills ...",
  "linkedin_text": "Experience ... Skills ..."
}
```

### Response (shape)
```json
{
  "version": "0.2.0",
  "score": {
    "overall": 0,
    "breakdown": {
      "section": 0,
      "keyword": 0,
      "completeness": 0,
      "consistency": 0
    }
  },
  "recommendations": [],
  "redaction": {
    "cv_text_redacted": "...",
    "linkedin_text_redacted": "..."
  }
}
```

## Validation
- Smoke test command:

```bash
python -m unittest tests/smoke/test_validate_endpoint.py
```

## Notes
- Deterministic scoring remains the source of truth.
- LLM integration is optional and scoped to narrative enrichment only.
